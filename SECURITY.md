# Security policy

## Reporting

Do not open a public issue for a vulnerability that could cause data loss,
arbitrary file access, command execution, or secret disclosure. Use the
repository host's private vulnerability-reporting feature or contact the
maintainers privately.

Include the version/commit, operating system, filesystem type, configuration,
reproduction steps, impact, and any proposed mitigation. Do not include real
private files.

## Support status

Until the first stable release, only the latest commit is supported. The current
Phase 2 release does not claim crash-safe recovery or safe cross-filesystem
transfer. Cross-filesystem movement is rejected by design.
